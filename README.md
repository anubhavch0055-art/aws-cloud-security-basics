## 📌 Project Overview

This project is a beginner-level learning project focused on understanding the basic concepts of **AWS Cloud Security**.

The project covers important AWS security concepts such as **IAM, Multi-Factor Authentication (MFA), Amazon S3 security, VPC concepts, and AWS CloudTrail**.

The main purpose of this project is to develop a basic understanding of how security can be considered while working with cloud infrastructure.

---

## 🎯 Objectives

* Understand the fundamentals of AWS Cloud Security.
* Learn the purpose of AWS Identity and Access Management (IAM).
* Understand the importance of Multi-Factor Authentication (MFA).
* Learn basic Amazon S3 security practices.
* Understand basic VPC and network security concepts.
* Learn how AWS CloudTrail can be used for monitoring and auditing.
* Develop a foundation for further learning in Cloud Security and Cybersecurity.

## 🔐 Security Concepts

### 1. AWS IAM

AWS Identity and Access Management (IAM) is used to control access to AWS resources.

Important concepts studied:

* Users
* Groups
* Roles
* Policies
* Permissions
* Least-privilege access

---

### 2. Multi-Factor Authentication (MFA)

MFA provides an additional authentication factor beyond a password.

Using MFA can help improve account security by requiring an additional verification method during authentication.

---

### 3. Amazon S3 Security

Amazon S3 is an object storage service.

Basic security concepts studied include:

* Access control
* Bucket permissions
* Avoiding unnecessary public access
* Secure access management
* Protecting stored data

---

### 4. VPC & Network Security

Amazon VPC provides a logically isolated network environment.

The project covers basic concepts such as:

* Virtual networks
* Subnets
* Security groups
* Network isolation
* Controlled network access

---

### 5. AWS CloudTrail

AWS CloudTrail can be used to record and monitor activity within an AWS account.

It can help with:

* Auditing
* Monitoring
* Tracking API activity
* Security investigation
